## Example structure (paraphrased from public extension guidance)

### Endangered Species Protection Requirements

Before application, check **Bulletins Live! Two** if this label requires it. Obtain a printable bulletin up to six months before application. Keep the bulletin with application records. If the field is in a **PULA**, follow additional geographic restrictions on the bulletin.

### Runoff / erosion mitigation

Each field must achieve a **minimum of 3 mitigation points** (unless exempt under label criteria) using practices from EPA’s Mitigation Menu / Runoff & Drift Calculator. Document how points were achieved.

### Spray drift

Do not apply when wind exceeds label limits. Follow nozzle, boom height, and buffer requirements on this label.
